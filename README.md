# MiCurso

**MiCurso** es una aplicación móvil que permite organizar a cada estudiante de la UC sus horarios semestralmente. Utilizando la información oficial de los cursos de [buscacursos.uc.cl](https://buscacursos.uc.cl), esta aplicación provee una búsqueda interactiva y amigable para el usuario.

## Características

- La aplicación permite manejar horarios de múltiples períodos académicos (2025-1 en adelante).
- La búsqueda de cursos considera filtros como:
	- Semestre
	- Nombre
	- Sigla
	- NRC
	- Profesor
	- Campus
	- Formato
	- Categoría
	- Área de formación general
	- Unidad académica
	- Período de admisión
	- Escuelas
	- Niveles
- Se muestra la ubicación de las clases en un mapa al acceder a la información de un bloque dentro de un módulo específico.
- Se notifica con 10 minutos de antelación la siguiente clase del calendario mostrado.
- La aplicación cuenta con configuración para modo claro y modo oscuro.

## Tecnologías utilizadas

- **Framework**: Expo v54 con React Native.
- **Estilización**: Estilos nativos de Expo y NativeWind (TailwindCSS).
